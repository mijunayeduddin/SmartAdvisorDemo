## 6. SPECIAL RULES & FLAGS

| Rule | Details |
|------|---------|
| **Waivable** | `ENG102` only. Waiving satisfies ENG103's prereq but adds 0 credits |
| **Alias / Dual-code** | `PHI104` ↔ `PHI401`, `ENV203` ↔ `GEO205`, `CSE325` ↔ `CSE425`, `EEE154` ↔ `CEE110`, `EEE111` ↔ `ETE111`, `CSE499A` ↔ `EEE499A` ↔ `ETE499A` |
| **Co-requisites** | Lab sections (L suffix) are co-reqs, never block lecture eligibility |
| **Credit thresholds** | CSE299: 60 cr; CSE498: 80 cr; CSE499A: 100 cr |
| **MAT116** | Listed as 0 credit in official degree plan (does not count toward 138 cr) |
| **PHY108 prereq** | Listed as MAT240 in CSV (likely MAT130 in practice — MAT240 does not exist in NSU BSCSE; treat as MAT130 + PHY107) |
| **CSE482 prereq** | Listed as CSE338 in CSV — CSE338 does not appear in catalog; likely a data entry error |
| **CSE445 prereq** | Listed as CSE348 in CSV — CSE348 does not appear in catalog; likely a data entry error |

## 8. DB FIELD REFERENCE (SmartAdvisor `curriculum_courses` table)

| DB Field | Type | Meaning |
|----------|------|---------|
| `program` | TEXT | `'CSE'` |
| `code` | TEXT | Primary course code (e.g. `CSE311`) |
| `aliases` | TEXT[] | Alternate codes (e.g. `['CSE311L']`) |
| `name` | TEXT | Display name |
| `credits` | NUMERIC | Credit hours (0 for free labs) |
| `grp` | TEXT | Group name (see §5) |
| `min_credits` | INT | Minimum completed credits before eligible (0 = no threshold) |
| `has_alternative` | BOOL | True if multiple code options exist (OR logic) |
| `raw_prereq` | TEXT | Raw prerequisite string from CSV |
| `unknown_prereqs` | TEXT[] | Prereq codes the parser couldn't resolve |
| `waivable` | BOOL | True for ENG102 only (CSE) |
| `elective_pool` | TEXT | Pool label for open elective grouping |
| `coreq_codes` | TEXT[] | Co-requisite course codes (non-blocking) |
| `has_waiver_option` | BOOL | Has optional waiver path → status = `maybe` |
| `special` | TEXT | `'ALL_COURSEWORK'` → status always `maybe` |
| `note` | TEXT | Advisory display text |
